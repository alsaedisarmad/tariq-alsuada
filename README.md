# القرآن الكريم وتفسيره · دروس تفاعلية

موقع واحد يجمع دروس مادة **القرآن الكريم وتفسيره** بهوية بصرية واحدة.

- **إعداد أستاذة المادة:** فاطمة الطلحي
- **مديرة المدرسة:** آمال باربود

## الدروس
| الرابط | الدرس |
|---|---|
| `hud/` | طريق الاستقامة · تفسير سورة هود ١١٢–١٢٣ (الوحدة الرابعة، الدرس العاشر) |
| `raad/` | طريق السعداء وطريق الأشقياء · تفسير سورة الرعد ١٩–٢٩ (الوحدة السادسة، الدرس الرابع عشر) |
| `ibrahim/` | الكلمة الطيبة والكلمة الخبيثة · تفسير سورة إبراهيم ٢٤–٣١ (الوحدة السابعة، الدرس الخامس عشر) |
| `ibrahim42/` | تهديد الظالمين وبيان عقوبتهم · تفسير سورة إبراهيم ٤٢–٥٢ (الوحدة السابعة، الدرس السادس عشر) |

الصفحة الرئيسة `index.html` تعرض الدروس الأربعة. كل درس ملف واحد يعمل بدون إنترنت (الخطوط والصوت مدمجة فيه).

## المشترك بين الدروس
- الرأس وشريط التنقل وخريطة الدرس ولوحة الأستاذة (المجموعات، المؤقت، اختيار طالبة، الشهادات، خطة الحصة).
- **الجرس:** زر الجرس في الرأس وأسفل لوحة الأستاذة (أو `B`) يقرع جرسًا بصوت ويظهر على الشاشة.
- **تنزيل الدرس:** زر «تنزيل الدرس HTML» أسفل لوحة الأستاذة ينزّل الدرس ملفًا واحدًا يعمل بدون إنترنت.
- **الشهادات في لوحة الأستاذة:** تبويب «الشهادات» يصدر شهادة لأي طالبة (النسبة اختيارية) للطباعة أو الحفظ صورةً، أو يجهّز شهادات كل الأسماء في تبويب «الطالبات» ويطبعها دفعة واحدة.
- المصحف بالعدسات والمعنى الإجمالي، وجدول التعلم.
- **التقويم والشهادة:** بعد التقويم في كل درس محطة «الشهادة» (shared/cert.html). من تجيب بنسبة ٧٠٪ فأكثر تُفتح لها الشهادة، فتكتب اسمها وتظهر شهادة باسمها موقّعة من أستاذة المادة، قابلة للطباعة والحفظ صورةً.

**اختصارات لوحة المفاتيح:** الأسهم للتنقل · `M` الخريطة · `T` المؤقت · `R` اختيار طالبة · `B` الجرس · `F` ملء الشاشة.

## هيكل المستودع
```
index.html, hud/, raad/, ibrahim/, ibrahim42/   الصفحات الجاهزة (تُبنى تلقائيًا)
shared/page.html                    هيكل صفحة الدرس
shared/base.css                     الهوية البصرية والمكوّنات المشتركة
shared/core.js                      التنقل والأدوات والتقويم والشهادة
shared/hub.html, hub.css            الصفحة الرئيسة
lessons/<درس>/lesson.html           محطات الدرس وخطة الحصة
lessons/<درس>/lesson.js, lesson.css تفاعلات الدرس وتنسيقه الخاص، مع ملفات الصوت والفيديو
assets/                             شعار الوزارة وتوقيع الأستاذة وصوت الجرس
fonts/                              الخطوط وتراخيصها (SIL OFL)
build.py                            يبني الصفحات
```

## التعديل
عدّلي ملفات `shared/` أو `lessons/` ثم شغّلي:
```
python build.py            # يبني الموقع
python build.py --desktop  # ويحدّث نسخ الدروس على سطح المكتب
```
