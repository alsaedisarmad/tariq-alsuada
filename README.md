# طريق السعداء وطريق الأشقياء · تفسير سورة الرعد (١٩–٢٩)

درس تفاعلي لمادة **القرآن الكريم وتفسيره**، الوحدة السادسة، الدرس الرابع عشر.

- **إعداد معلمة المادة:** أ. فاطمة الطلحي
- **مديرة المدرسة:** أ. آمال باربود

## تشغيل الدرس
- **عبر الإنترنت:** افتحي رابط GitHub Pages الخاص بالمستودع.
- **بدون إنترنت:** نزّلي ملف `index.html` وافتحيه في Chrome أو Edge. الخطوط والصوت مدمجة داخل الملف.

## محتوى الدرس
٢٥ محطة في خمسة فصول: البداية، الآيات، الطريقان، الأثر، الختام. من أبرزها:
- ميثاق الصف بأربع نجمات، وإشراقة صباحية، وشريط لمراجعة الدرس السابق.
- حديث الأعرابي في محادثة، وربط أعماله بآيات الدرس (أستهلّ).
- الآيات أولًا، ثم الأهداف: مصحف بأربع عدسات (صفات السعداء، صفات الأشقياء، المفردات، القلقلة) مع المعنى الإجمالي لكل آية والاستماع للآيات.
- مفترق الطريقين: سحب صفات السعداء والأشقياء إلى طريقها وكشف عاقبة كل طريق.
- الفوائد والأحكام: البصيرة، الخشية، دلالة إفراد الصلاة والزكاة، أبواب السلام، صلة الرحم، الرزق مفهوم واسع، مفاتيح الرزق، الذكر وطمأنينة القلوب، الإيمان قول وعمل.
- أربط، وصيد مواضع القلقلة، وأنواع الصبر، والمشروع، وبطاقة أثر قابلة للطباعة والحفظ صورة.
- تقويم ختامي، والفوائد المتميزة، وغلق الدرس.
- لوحة للمعلمة: نقاط المجموعات، ومؤقت، واختيار طالبة عشوائيًا، وخطة الحصة (٤٥ دقيقة).

**اختصارات لوحة المفاتيح:** الأسهم للتنقل · `M` الخريطة · `T` المؤقت · `R` اختيار طالبة · `F` ملء الشاشة.

## هيكل المستودع
```
index.html        الدرس الجاهز (ملف واحد، يُبنى تلقائيًا)
src/lesson.html   هيكل المحطات
src/style.css     التصميم
src/app.js        التفاعل
assets/           شعار الوزارة والصوت
fonts/            الخطوط وتراخيصها (SIL OFL)
build.py          يدمج الملفات في index.html
```

## التعديل
عدّلي ملفات `src/` ثم شغّلي:
```
python build.py
```
