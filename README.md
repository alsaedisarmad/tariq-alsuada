# القرآن الكريم وتفسيره · دروس تفاعلية

موقع واحد يجمع دروس مادة **القرآن الكريم وتفسيره** بهوية بصرية واحدة.

- **إعداد معلمة المادة:** أ. فاطمة الطلحي
- **مديرة المدرسة:** أ. آمال باربود

## الدروس
| الرابط | الدرس |
|---|---|
| `hud/` | طريق الاستقامة · تفسير سورة هود ١١٢–١٢٣ (الوحدة الرابعة، الدرس العاشر) |
| `raad/` | طريق السعداء وطريق الأشقياء · تفسير سورة الرعد ١٩–٢٩ (الوحدة السادسة، الدرس الرابع عشر) |
| `ibrahim/` | الكلمة الطيبة والكلمة الخبيثة · تفسير سورة إبراهيم ٢٤–٣١ (الوحدة السابعة، الدرس الخامس عشر) |

الصفحة الرئيسة `index.html` تعرض الدروس الثلاثة. كل درس ملف واحد يعمل بدون إنترنت (الخطوط والصوت مدمجة فيه).

## المشترك بين الدروس
- الرأس وشريط التنقل وخريطة الدرس ولوحة المعلمة (المجموعات، المؤقت، اختيار طالبة، خطة الحصة).
- المصحف بالعدسات والمعنى الإجمالي، وجدول التعلم.
- **التقويم والشهادة:** من تجيب بنسبة ٧٠٪ فأكثر تكتب اسمها فتظهر لها شهادة باسمها، موقّعة من معلمة المادة، قابلة للطباعة والحفظ صورةً.

**اختصارات لوحة المفاتيح:** الأسهم للتنقل · `M` الخريطة · `T` المؤقت · `R` اختيار طالبة · `F` ملء الشاشة.

## هيكل المستودع
```
index.html, hud/, raad/, ibrahim/   الصفحات الجاهزة (تُبنى تلقائيًا)
shared/page.html                    هيكل صفحة الدرس
shared/base.css                     الهوية البصرية والمكوّنات المشتركة
shared/core.js                      التنقل والأدوات والتقويم والشهادة
shared/hub.html, hub.css            الصفحة الرئيسة
lessons/<درس>/lesson.html           محطات الدرس وخطة الحصة
lessons/<درس>/lesson.js, lesson.css تفاعلات الدرس وتنسيقه الخاص، مع ملفات الصوت والفيديو
assets/                             شعار الوزارة وتوقيع المعلمة
fonts/                              الخطوط وتراخيصها (SIL OFL)
build.py                            يبني الصفحات
```

## التعديل
عدّلي ملفات `shared/` أو `lessons/` ثم شغّلي:
```
python build.py            # يبني الموقع
python build.py --desktop  # ويحدّث نسخ الدروس على سطح المكتب
```
